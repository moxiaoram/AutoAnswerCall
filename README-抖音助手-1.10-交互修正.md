# 抖音助手 1.10 源码修改说明

基于 1.9 源码，针对抖音 40.8.0。

## 更新

1. **进度条位移保持**：在 `AWEPlayInteractionProgressContainerView` 和 `AWEFeedProgressSlider` 的 `setTransform:` 路径重新计算位置，而不只在 `layoutSubviews` 里单次平移。默认 +6pt、限幅 ±12pt；父容器已位移时避免对子滑块叠加位移。保留原有安全布局模式（不会拉伸信息流容器）。
2. **长按直接出面板**：对视频 Feed Cell 额外安装不取消原生触摸的长按识别器（0.43秒），提前显示自定义面板。原生控制器稍后出现时会绑定其已有操作模型，避免重开和闪面板。直接长按时内置保存视频和解析下载地址的模型回调。保留原生菜单入口以应对缺失的私有动作。
3. **图片合集全屏快速浏览**：点击图片 Feed Cell 的图片区域或点击信息流缩略图，会进入自带全屏图片浏览器（依赖模型 `albumImages`，至少 2 张）。支持左右滑动分页、底部全图缩略列表、点击缩略图跳转、选中状态动画、滚动居中、图像淡入、关闭以及预加载相邻图片；原有图集底部缩略栏仍保留。
4. **语义设置图标**：用系统 SF Symbols 按条目名称语义选择图标及颜色，涵盖点赞、评论、保存、图集、音频、画质、进度、隐藏、全屏等；旧系统不可用的单个符号自动回退。无需引入网络下载图片、第三方字体包或图标资源。

## 限制和测试

- 本次**未在 iOS 真机或抖音 40.8.0 上实际验证**；本地无 Theos / iOS SDK，无法生成 DEB。仅进行代码结构与 ZIP 完整性校验。
- 图片的 CDN URL 必须是可通过当前网络请求访问的 URL。需要登录 Cookie、特殊签名或应用内自定义图片缓存协议的图集，可能仍加载失败。原有操作不应被视为完全兼容。
- 第三方 App 的非公开播放器/图集 ViewModel 可能随版本改变。若长按操作、分页或进度条仍不生效，应导出 `DYYY-40.8.0-compat.txt` 运行时类名报告并检查实际类名及方法（报告只记类名及数目，不包含私密内容）。
- 直接长按识别与抖音自身的长按动作可能并发，已使用原生手势同时识别与独立覆盖窗口降低闪屏，但不能在未真机验证的情况下承诺完全无闪屏。

## 建议的真机回归测试

1. 连滑 8 条视频，确认进度条位置不再重置、每条视频保持整屏对齐。
2. 从首页推荐视频长按，确认无需下拉即出现插件面板；保存、解析按钮可操作，关闭后信息流没有被隐藏。
3. 打开 3 张以上的图集，测试点击画面、缩略图、左右滑动、滑到最后一张及关闭。
4. 查看“基本”“视频播放”“评论与互动”“下载与保存”等分区是否出现不同的图标和颜色。
5. 如有兼容问题，请保留旧版备份，重新安装前先退出抖音进程，确认设置页版本号显示 1.10。
