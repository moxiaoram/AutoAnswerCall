# 2.0.7 视觉与长按操作修复（源码层面）

- 底栏背景：在旧版仅清除 AWENormalModeTabBar 自身的基础上，增加严格限定在底栏几何范围内的祖先容器背景清除；保留原始颜色与 opaque 状态供关闭时恢复。不会放大 Feed 的 frame，因此如果视频本身没有绘制到底部，无法保证视觉上出现视频画面。
- 评论区毛玻璃：保留 UIViewController 评论容器模糊层；额外清理评论列表、可复用 Cell 和 contentView 里的不透明背景，恢复配置关闭时的原色。保留按钮、文字和图片，避免粗暴地隐藏全部视图。
- 长按菜单：继续支持直接显示；原生模型延迟到达时将其和提前提供的保存／解析动作合并，保持原生操作；启用自定义面板时不再让“精简长按”选项清空原生模型；允许原生倍速模型在额外操作中出现。提供“打开抖音原生完整菜单”入口，若尚未生成原生控制器，会提示而不是打开空白页。
- 2.0.7 新安装的默认值：底栏透明、评论区毛玻璃均默认开启，透明强度为 0.82；已有显式开关设置不会被覆盖。
- 构建：RELAXIN / RootHide，iOS 17.3，抖音 40.8.0，严格链接；**禁止** `-Wl,-undefined,dynamic_lookup`。

## 校验边界
静态检查与 ZIP 完整性不能证明 iOS 40.8.0 的私有 View 层级、原生动作回调或视频下方的内容都兼容。请编译后逐项验证：①评论区滚动／新评论复用后是否透明；②评论弹层关闭后页面是否正常；③首页／消息页底栏是否透明且触摸正常；④长按是否直出、是否能进入原生完整菜单和使用官方操作。
