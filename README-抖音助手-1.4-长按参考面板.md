# 抖音助手 1.4 · 参考图风格长按面板

基于上一版 1.3 完整源码，保留 1.3 的 iOS 系统设置风格、底栏透明方案，以及 1.2 的「解析下载地址」功能。本次重点将 1.3 的全页面双列卡片长按菜单调整为用户参考图所示的布局。

## 使用

- 抖音助手设置 → 长按相关设置 → **长按同款圆形快捷面板**，设置键保持 `DYYYGridLongPressPanel`，与 1.3 配置兼容；未单独配置时默认开启。
- 长按标准视频时会由原生菜单控制器展示新抽屉；特殊视频/广告/直播不包含标准 ViewModel 时保留原生面板。

## 参考图布局

1. 深灰黑色圆角底部面板，上方居中灰色拖动条，下拉拖动条可关闭。
2. 顶部一行五个圆形操作：推荐一下、赞赏、下载、稍后再看、听视频。优先绑定当前抖音版本对应 ViewModel；未提供动作的按钮降低透明度，点按提示当前视频未提供此操作。
3. 中部深色圆角分组：不感兴趣、举报、倍速（0.5x / 1x / 1.5x / 2x）。倍速复用本项目已存在的播放器速率接口，仅在找到支持的可见播放器时执行。
4. 底部分组按当前版本 ViewModel 动态加入弹幕操作和保存视频到相册，同时展示「自动上滑」「后台播放」两个真实开关，分别对应原项目 `DYYYEnableAutoPlay` 和 `DYYYEnableBackgroundListen`。
5. 剩余的插件/原生操作（如保存封面、音频、解析下载地址、复制文字等）保留在下方「更多操作」双列区；需要时可滑动面板查看。
6. 点击「查看原生面板中的其他操作」可返回原生面板。未公开 action 的原生操作也自动回到原生面板，而不是调用不可靠的选择器。

## 注意事项

- 参考图来自另一个版本的界面，不保证抖音 40.8.0 一定提供全部同名原生功能；没有 ViewModel 的功能不会凭空实现。
- 「自动上滑」对应原插件的**自动播放/自动连播**功能，不是额外编写的滑屏模拟器。
- 顶部/其他原生菜单按钮如果没有可公开调用的 `action`，会退回原生面板进行操作。
- **本包仅检查源码结构及压缩包完整性，未在 Theos / iOS SDK 编译，也未在抖音 40.8.0 真机验证。** 安装前请备份、注意与其他长按菜单插件的 Hook 冲突。
