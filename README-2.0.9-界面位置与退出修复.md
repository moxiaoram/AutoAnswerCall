# 2.0.9 进度条 / 底栏 / 设置导航回归修复

目标设备：iPhone15,3，iOS 17.3，RELAXIN RootHide，抖音 com.ss.iphone.ugc.Aweme 40.8.0。

## 1.7 → 2.0.8 → 2.0.9 对照

* 1.7 进度条在 layoutSubviews 写入平移；2.0.8 改为 transform 缓存，但切换设置时可能将旧平移原样通过。2.0.9 为进度条容器、单独滑块分别保存原生变换、上次平移和配置值；视频复用和设置值更改后会重新合成。
* 1.7 标题直接平移；2.0.8 只在布局后检查，原生 UIKit 后续写入会覆盖。2.0.9 同时 Hook 原生 setTransform: 与 layoutSubviews，并保留原生 transform，不累加平移。
* 2.0.8 底栏黑色不等于背景隐藏失败；视频根本没渲染到底栏后面也会是黑色。2.0.9 放宽仅播放器视图的延伸判定（36–135pt 且接近底栏高度）；不改变 UICollectionView/UITableView 的整页高度。不同类型视频使用的播放器视图可能不一致，仍需设备验证。
* 2.0.8 两种导航逻辑并存，并且双指入口仍有空白临时控制器。2.0.9 删除临时控制器，统一以单个全屏模态 UINavigationController 呈现；插件根页左滑或返回时 dismiss 导航控制器。

## 建议测试

1. 连续滑动 10 条视频，检查进度条下移 10pt、底栏文字下移 6pt；再在设置中改为 15pt/10pt，返回无需重启或重启后再次核对。
2. 打开/关闭「隐藏底栏背景」，比较视频是否确实显示在底栏文字后面；注意视频黑边源于 aspect fit 时需要另外处理。
3. 从侧栏、原生设置列表、双指入口进入插件，向右滑或点关闭，确认只退出一次且无白色空白页。
4. 检查评论和长按原生功能未受本次定位与导航修改影响。
