# ClashAssist 0.3.2 · 调用观测与状态机实验版

面向 iOS 17.3 RootHide、arm64e，仅注入 `com.supercell.magic.china`。本包仍是**调用观测 + 本地模拟版，不是可直接运行的真实自动战斗机器人**。

## 0.3.2 改动

- 将筛选、部署、资源监测、结束和结算整理为事件驱动状态机入口：`CALabOnSearchResult`、`CALabOnUnitDeployed`、`CALabOnBattleSecond`、`CALabObserveResources`、`CALabOnBattleEnded`、`CALabCompleteSettlement`。
- 资源观测使用 64 位快照；金币、圣水或黑水任一数值发生变化都会清零无增长计时。
- 全部 8 个单位部署后，连续 5 个一秒采样周期没有资源增长时进入结算状态。
- 每次新战斗都会清空该场的资源观测基线和无增长计时，避免上一场状态泄漏。
- 保留总搜索上限、总战斗上限、单场超时、循环开关和手动/后台停止。
- 增加事件驱动接口与 64 位资源快照测试，覆盖超时后回到下一轮搜索；UI 明确显示真实战斗后端尚未接入。

## 当前能力边界

- `CALabTick` 只推进本地合成模拟数据，不会点击真实游戏按钮。
- `CAObserve.m` 只对三个候选入口透传并统计调用次数，不调用搜索、部署或结束动作。
- 目前没有可靠的真实资源读取器，也没有经过验证的搜索、部署和结束函数调用适配器。
- 不能只凭函数偏移和入口指令指纹推断函数签名、参数含义、调用线程或生命周期。直接猜测并调用可能造成崩溃、错误操作或账号风险。
- 因此，0.3.2 **不会声称已经实现真实自动搜索、自动下兵或自动结束真实对局**。事件驱动状态机只是后续接入已验证后端的基础。

要接入真实后端，至少需要针对当前游戏构建验证：准确的游戏版本/主程序 UUID、搜索和部署操作的函数签名及调用约束、资源数值的可靠来源、结束/结算完成的确认条件。现有的 60 秒调用计数报告可以帮助缩小调查范围，但计数本身不能确认参数和语义。

## 使用本地模拟

1. 安装 deb 后完全退出游戏并重新打开。
2. 点击“实验”悬浮球。
3. 设置最低模拟金币/圣水/黑水、总搜索上限、战斗上限、单场超时和是否循环。
4. 点击“开始模拟”。每约 0.7 秒推进一个模拟秒；样本和收益仅由本地公式生成。
5. 点击“立即停止”或长按悬浮球可停止；切到后台会停止模拟。
6. 如需观测手动操作，点击“观测手动操作 60 秒”，手动操作游戏后复制调用计数报告。报告只反映调用次数，不证明函数用途已确认。

## RootHide 构建

```sh
make clean
make package FINALPACKAGE=1 ARCHS=arm64e THEOS_PACKAGE_SCHEME=roothide
```

本地 C 状态机测试通过不等于 iOS 注入、UI 或真实对局已验证。真机横屏布局、键盘、旋转、前后台和 Hook 兼容性仍需单独测试。
