# ClashAssist 0.1.1：RootHide 注入诊断版

0.1.1 修复：控制器声明游戏横屏方向，悬浮面板按窗口安全区计算布局，停止按钮固定底部，其余内容可滚动。尚需设备再次安装验证。

目标：iOS 17.3 RootHide；只注入 com.supercell.magic.china。分析基线为 18.116.1。当前为诊断版，不是自动战斗完成版。

## 已实现

- 应用前台显示悬浮按钮，拖动位置，点击展开/收起面板。
- 最低金币、圣水、黑水配置；最大搜索次数、战斗次数、超时和循环配置；保存在目标应用自己的 NSUserDefaults。
- 配置整数校验；长按按钮和面板按钮停止；失去前台时停止并隐藏。
- 面板显示注入成功与当前应用版本；开始按钮明确禁用。

## 尚未实现

资源监测、自动匹配、下兵、自动攻击、自动结束和循环执行。主程序业务符号已 strip，已发现的字符串不能作为函数地址使用。没有伪造接口、固定偏移或模拟资源值。参数目前仅持久化，不会驱动游戏操作。

## 构建

使用 RootHide 分支 Theos：https://github.com/roothide/theos ，匹配的 iPhoneOS SDK 和签名器。

```sh
make clean
make package FINALPACKAGE=1 ARCHS=arm64e THEOS_PACKAGE_SCHEME=roothide
```

不要仅修改普通 rootless 包的 Architecture 字段来冒充 RootHide。实际构建与静态检查状态见 build/ 目录。

## 首次设备验证

安装成功后，在 RootHide 的插件注入管理中确认允许此游戏加载插件，完全退出游戏后重开。应显示“辅助”悬浮球，面板显示“注入成功”和实际游戏版本。没有球时先排查注入；此现象不能靠自动化逻辑解决。

检查拖动、旋转横屏、展开/收起、键盘输入、保存重开、长按停止、退后台隐藏、返回前台恢复。尚未进行设备运行验证。
