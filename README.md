# ClashAssist 0.2.0 本地模拟实验版

面向 iOS 17.3 RootHide，arm64e。保留游戏内悬浮入口（仅 com.supercell.magic.china），运行独立的模拟状态机；没有读取游戏内存、模拟触摸、游戏协议请求、反检测或真实对局自动化。

## 使用

1. 安装 deb 覆盖旧版，完全退出游戏后重开。
2. 点击“实验”悬浮球。标题持续标注“本地模拟 · 非真实对局”。
3. 设置模拟资源门槛、总搜索上限、场次上限、单场超时和是否循环；点击“开始模拟”。
4. 观察资源筛选、8 个模拟单位部署、模拟收益变化及结算日志；每 0.7 秒推进一个模拟秒。单场正常 12 个模拟秒完成；超时包含部署阶段。
5. 点击“立即停止”或长按球终止；离开前台停止，不自动恢复运行。可复制最多 80 行本地模拟日志。

模拟资源来自固定公式，金币和圣水各在 10万–200万，黑水 0–2万。门槛超过生成范围时将搜索至上限停止，不强行让样本通过。所有资源门槛同时满足才进入部署。搜索上限按整个运行累计，不在每场重置。

## 实现与验证

- CALabCore.h：独立 C 状态机，无 UIKit/网络/进程依赖。
- CALabUI.m：自适应布局；固定标题、状态和操作栏；仅配置和日志区滚动；每次展开回到顶部。
- tests/lab_core.c：筛选、精确收益、单次/循环、次数上限、超时、各状态停止及配置错误测试。
- GitHub Actions：先运行状态机测试，再使用 RootHide Theos 构建签名和打包。

本机测试：

```sh
cc -std=c11 -Wall -Wextra -Werror -I. tests/lab_core.c -o /tmp/clash-lab-test
/tmp/clash-lab-test
```

RootHide 构建：

```sh
make clean
make package FINALPACKAGE=1 ARCHS=arm64e THEOS_PACKAGE_SCHEME=roothide
```

真机待验：横屏布局、键盘/保存、开始后日志推进、长按停止、切后台停止、旋转和再次展开。构建通过与核心测试不等于真机验证通过。
