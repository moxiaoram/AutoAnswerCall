# 影流助手 2.0.18（RELAXIN / RootHide）

本版继续基于 2.0.17 源码，重点调整：

- 将搜索/详情页中使用不同私有控制器的视频长按菜单，纳入统一的自定义长按面板；推荐页与搜索页共用 `DYYYGridLongPressPanel`，保留原生数据并合并插件动作。
- 移除插件设置首页资料卡右侧的圆形 X，仍可通过原有左边缘滑动退出。
- 二级设置标题不再显示冗余的“基本”前缀；兼容层会自动清理旧调用传入的该前缀。
- 保留 2.0.17 的关注小星星、四个互动图标、RootHide 严格链接参数与 GitHub Actions 构建流程。

目标环境：抖音 40.8.0、iOS 17.3、RELAXIN 0.4.8、RootHide。静态检查不代表已完成 Theos 编译或真机验证。
