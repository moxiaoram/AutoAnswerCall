# AutoAnswerAudio 2.1.2 — 通话界面与上行播放修订源码

## 本次改动

1. `InCallService` 中启用周期性视图扫描，尝试把原生通话界面的“添加 / Add call”槽位替换为**同尺寸**“停止”圆形按钮，保留“免提”“静音”“拨号键盘”“结束”等系统功能。点击后通过 Darwin 通知让 `SpringBoard` 停止插件的 TTS 朗读、关闭上行混音（如可用）、解除插件的麦克风静音，**不会主动挂断**。
2. `InCallService` 监测拨号键盘展示 / 关闭，并把状态通知给 `SpringBoard`；键盘展示期间不允许备用悬浮停止按钮覆盖数字。键盘关闭后恢复适当的按钮可见性。
3. 增加系统内嵌按钮“存活心跳”；仅当内嵌按钮不可用时保留备用 SpringBoard 停止悬浮按钮，避免叠加。在备用模式中将原来固定 `64pt` 的圆形改为近似系统控制直径的 `82pt`；内嵌模式的直径直接沿用原生控件测量值。
4. 免提 / 听筒等路由切换时不主动结束用户的播放；增加 `AVAudioSessionRouteChangeNotification`、音频中断结束以及 TTS 意外取消的恢复处理。**若仍正常朗读，则保持原有播放；若意外中断，则尝试重新启动。**
5. 仍然保持停止后关闭循环、尝试恢复麦克风的逻辑。原自动接听逻辑保留。

## 重要限制

- 当前交付的是**修改过的源码**，不是已验证的 iPhone 安装包；这里没有 Theos / iOS SDK / RootHide 真机环境，无法编译或验证注入与通话音频路由。
- `InCallService` 是私有系统界面，iOS 版本 / UI 结构会影响能否定位“添加”；若无法定位，只会保留备用停止入口。需以真机日志确认实际行为。
- 原项目使用 **TTS 朗读并尝试混入电话上行**，而非直接解码用户音频文件。`setMixToTelephonyUplink:`、`setUplinkMuted:` 等私有接口是否生效取决于系统，**对方能否听到、免提切换后能否无缝恢复尚未验证**。
- 拨号盘与控制界面需要在设备上以非隐私号码试通话。停止后请验证对方能实时听到人工讲话。

## 真机验收清单

- [ ] 进入通话主界面，“添加”位置出现与原生按钮同直径的“停止”；没有叠加红色悬浮按钮。
- [ ] 切到数字拨号界面，1~9、*、0、# 均无遮挡，数字界面本身保持显示直到用户主动关闭。
- [ ] 通话中播放插件朗读，打开/关闭免提，朗读未因该操作被标记为“用户停止”；如果系统打断，能尝试恢复。
- [ ] 点击“停止”，朗读循环结束、麦克风解除插件静音，对端能听到真人讲话，**通话仍保持连接**。
- [ ] 通话结束后按钮清除，新通话可再次正常出现、使用；无法注入时应有备用停止入口。
