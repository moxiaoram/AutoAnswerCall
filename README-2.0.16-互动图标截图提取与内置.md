# 影流助手 2.0.16：四个互动图标与抖音按钮尺寸对齐

本版从用户提供的抖音截图中提取四种白色描边图标，并以透明 PNG 保存于 `assets/feed-icons/`：

* `like_before.png`：双层爱心（未点赞）
* `comment.png`：双层评论气泡
* `unfavorite.png`：五角收藏星（未收藏）
* `share.png`：分享箭头

生成的资源已内嵌到 `DYYYCapturedFeedIcons.m` 的 PNG 数据中，因此不依赖手机上某个手工放置的目录。`AWEFeedVideoButton setImage:` 优先使用用户已有自定义图标；否则，默认应用截图同款图标。插件只替换图片，不调整原生按钮容器的 `frame`、`bounds`、`transform` 或触摸响应区域，也不修改右侧数值与排列方式。选中点赞/收藏继续显示抖音原生激活样式。

由于输入是 JPEG 压缩后的截图，而非抖音 IPA 中的原始矢量资源，轮廓和前后两层细节尽量保持，但**像素级完全一致无法保证**。图像会跟随原按钮图片尺寸进行中心化渲染，图案的可见宽度约为 20-22pt，依 UIKit 实际图片框裁切。可在界面设置的图标区关闭此项，恢复原生图标。

本版无意改变 2.0.15 的视频解析、菜单、底栏及评论区逻辑。RootHide 仍使用 `arm64` dylib、`iphoneos-arm64e` deb、严格链接，且不支持动态查找模式。

**验证限制：** 通过源码静态测试和 ZIP 完整性检测不等于已完成 Theos 编译和真机匹配验证。
