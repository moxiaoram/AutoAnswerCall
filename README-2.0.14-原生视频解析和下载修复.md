# 2.0.14 视频直链解析与下载修复（RootHide）

## 从外部备份中能核实什么
用户提供的「抖音图层_BackupFiles.zip」只有 `UserDefaultsBackup.json`，其内容是 Base64 形式的高熵二进制数据（约 419728 字节），不是可读取的 JSON 或接口配置。无法凭该文件核实对方的解析 API URL，因此本版**没有捏造或硬编码第三方接口**，也没有试图复制任何账户鉴权信息。

## 本版功能
- 默认直接从当前视频的播放模型、可用清晰度列表、H.264 和低码率备用列表提取 HTTPS/HTTP 视频 URL（复制时可选清晰度）。
- 保存视频时优先尝试较高码率地址，下载失败后在前五个不同候选地址中依次尝试；所有失败会提示。
- 对下载 HTTP 403/404、HTML/JSON 错误页进行拒绝，避免当作 MP4 存相册。
- 兼容无第三方接口时的长按直链复制；配置了自己的可用解析 API 且当前视频无直链时再使用 API。接口默认不填。
- 修正外部 API 分享链接编码与非法 URL 防护。

## 限制
- 无法保证所有视频都公开可用的模型直链，部分 URL 可能限时、需登录或特定请求头。
- 当前单文件下载器不支持 HLS/DASH 分段流；会跳过 `.m3u8` 和 `.mpd`。
- 本地已执行源码结构和回归静态检查，但尚未使用 macOS Theos 或真机完成验证。
- 仍保留 RootHide 严格链接，不使用 `-Wl,-undefined,dynamic_lookup`。
