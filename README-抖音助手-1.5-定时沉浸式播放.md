# 抖音助手 1.5：定时沉浸式视频播放

在 1.4（参考图同款长按面板）完整源码基础上新增；其他功能和原有设置保留。

## 设置入口

**抖音助手 → 基本设置 → 视频播放**：

- **定时沉浸式全屏播放**：独立开关（默认关闭，需要手动开启）。
- **进入沉浸模式时间**：输入 5～3600 秒，默认 **60 秒**，使用 iOS 风格设置界面和带图标的设置项。

备用/旧版设置页面同步提供相同两个配置项。

## 工作机制

1. 仅在首页推荐 Feed 显示且播放进度实际前进时累计时间；暂停或卡顿不会单独增加累计值。
2. 播放累计达到设置秒数后，用 **1.25 秒缓动动画**渐隐视频顶部、底部导航、视频右侧交互控件、标题、进度等操作层，视频仍正常播放；按当前全屏布局 Hook 尝试将视频延伸到屏幕底部。
3. 用户单击/上下滑动时恢复（0.23 秒动画），计时清零；再次累计达到阈值时再次触发。
4. 换视频、离开首页 Feed 或应用转后台都会恢复并清零；进度跳播不算观看时间。
5. 与原来的手动一键清屏功能相互独立，不需要开启悬浮清屏按钮。

## 兼容性与已知限制

- 针对项目内抖音 40.8.0 的私有播放器进度 Hook 编写，后续 App 版本可能调整对应类与回调。
- 尽量只透明化控件层，避免影响视频渲染；如果抖音将新控件放到未知类名中，该控件可能仍显示。
- 部分布局可能被抖音自身约束重新覆盖；实际是否铺满至底部需真机验证。
- 未提供运行中改变淡出秒数的设置，目前固定约 1.25 秒。
- 本源码没有完成 Theos/iOS SDK 真机编译或实际运行验证。

主要新增文件：`DYYYImmersivePlaybackManager.h` 与 `.m`。`DYYY.xm` Hook 新增播放进度触发与 Feed 生命周期处理，`DYYYSettings.xm`、`DYYYSettingsHelper.m`、`DYYYSystemSettingsViewController.m` 等新增设置，`Makefile` 加入新源文件。
