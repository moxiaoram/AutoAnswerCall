# 影流助手 2.0.12 — 长按边缘倍速兼容修复

## 问题及修复

2.0.10 同时在 Feed Cell 和 Feed UITableView 上添加非取消式 UILongPressGestureRecognizer，未判断手指水平位置。
这会导致视频两侧长按与抖音原生倍速手势同时触发，插件抢先显示菜单。

2.0.12 在两个插件识别器共享的 DYYYFeedLongPressRelay 中实现 `gestureRecognizer:shouldReceiveTouch:`，在手指落下时按 UIWindow 水平坐标过滤。
从屏幕两端起约 20% 宽度（60～100 pt）内的触摸不会启动插件识别器，留给抖音原生边缘长按倍速；中间区域仍可长按直接打开插件面板。
在进入 `UIGestureRecognizerStateBegan` 时再次检查，防止触摸移入边缘后误弹面板。Feed 识别器仅在 Cell 没有安装同类识别器时作为兜底，避免一按弹出两次。

## 不更改

- 不移除原生长按倍速的私有实现，不替换 Douyin 的倍速手势；只避免插件抢占边缘触摸。
- 不修改 `AWEFeedTableView` 的高度、Feed Cell 的布局、评论区、底栏或原长按菜单操作模型。
- 保留 RootHide/RELAXIN iOS17.3/抖音40.8.0 的严格链接；不允许 `-Wl,-undefined,dynamic_lookup`。

## 真机验证步骤

1. 选择一个普通推荐页视频，**长按屏幕左侧和右侧**：应保持抖音原生临时倍速播放，松手恢复。
2. **长按视频中央**：应直接弹出插件长按面板，保存及解析入口仍在。
3. 连续上下滑动至少 5 条视频后重复测试；兼顾横版有留黑边的视频。
4. 关闭「长按同款圆形快捷面板」后，确认不再出现插件快捷面板。
