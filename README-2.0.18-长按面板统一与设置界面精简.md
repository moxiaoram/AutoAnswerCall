# 影流助手 2.0.18 — 长按面板统一与设置界面精简

## 修改内容

1. 新增视频长按控制器兜底：对名称包含 `LongPressPanel`、实现 `dataArray` 且非评论长按菜单的控制器，在 `viewDidAppear` / `viewDidLayoutSubviews` 时使用 `DYYYGridLongPressPanel` 渲染。这样搜索、详情等使用其他私有控制器的场景也进入同一面板。
2. 推荐页的早期手势面板继续使用同一渲染器。原生控制器晚到时，沿用现有合并逻辑，将官方动作与首页快速下载/解析等回退动作合并，避免两套布局。
3. 移除设置首页资料卡右侧的圆形 X，扩大插件名称标签可用宽度；保留左边缘滑动退出和二级页返回。
4. 二级设置页标题移除冗余“基本”前缀，当前“基本设置”页显示为“设置”；在 `DYYYSettingsHelper` 中也集中处理旧调用。

## 自检范围

新增 `scripts/check_218_panel_settings.py` 并纳入 GitHub Actions；检查面板路径、设置标题、X 按钮移除、RootHide 严格链接和 CI 步骤。此为静态源码检查，不等于 Theos/Logos 实际编译或真机行为验证。搜索页真实私有控制器名称和原生数据时序仍需在目标抖音版本实测。
