# AutoAnswerAudio v2.1.4 — 停止按钮红/灰状态

## 本版改动

- 插件播放启动通知到达 `InCallService` 后，原生“添加”槽位替换出的“停止”按钮切换为红色圆形背景。
- 点击停止后立即标记为已停止，发送现有停止通知，保留原来的停止朗读、恢复麦克风和不挂断电话流程；停止按钮恢复其原始系统灰色/材质背景。
- 在 `InCallService` 的 UI 扫描周期中重新应用状态，尽量避免系统重新布局后把按钮颜色覆盖回去。
- 兼容视图扫描模式也使用同一状态：播放期间红色，停止后灰色，不再用整体 alpha 变暗来模拟停止状态。
- 颜色恢复使用首次识别到的系统背景色和圆角值，而不是猜测一个灰色，因此目标是与系统原生按钮的未激活外观一致。

## 需要真机验证

此版本通过运行时遍历原生“停止”控件的视图层级，寻找圆形背景视图并修改颜色。不同 iOS 版本可能采用不同的私有视图结构；如果系统把按钮背景绘制在独立材质层或私有图层中，仍需根据设备日志/视图层级调整。该源码尚未在 Theos/iOS SDK 环境中编译，也未做 RootHide 真机验证，不能视为已验证的 `.deb`。

## 构建

```sh
cd AutoAnswerAudio
make clean
make package THEOS_PACKAGE_SCHEME=roothide
```

建议先备份现有 2.1.3 包。测试时确认：播放期间停止按钮红色；按下后按钮立即恢复系统灰色；朗读停止、麦克风恢复、通话不断开；下一次播放开始后按钮重新变红。


## v2.1.5 修复

- 使用同尺寸覆盖控件控制停止按钮背景色，播放中红色，停止后系统灰色。
- 通过 playback-state.plist 与心跳同步 SpringBoard / InCallService 状态。
- 使用持久 CXCallObserver 监听挂断，立即移除备用悬浮按钮。
- 备用悬浮按钮只有在确认存在活动通话时才允许显示。
- 尚需 Theos 编译和 RootHide 真机验证。
