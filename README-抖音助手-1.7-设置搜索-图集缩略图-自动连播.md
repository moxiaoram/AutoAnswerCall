# 抖音助手 1.7 — 设置搜索、图集缩略图、自动下一条

基于 1.6 完整源码增量修改，面向抖音 40.8.0。源码供自行编译与测试。

## 功能

1. **设置页**：iOS 分组卡片、彩色 SF Symbols 图标、标题、版本信息及顶部搜索框。支持以设置标题、说明和所属分类查找约 277 个设置条目；搜索结果可打开所在分类并定位直接子设置项。部分更深层设置仍需在分类中继续进入下一层。
2. **图片合集**：在图集 Feed Cell 底部显示可横向滚动的缩略图（默认开启）。当前图片加白边并使用缩放动画，点击缩略图优先通过原生横向 ScrollView/CollectionView 切换；若当前抖音版本无法识别原生分页容器，则以覆盖图片预览回退，预览可点击关闭及左右滑动切换。缩略图后台异步加载，尽量只加载可见范围。
3. **自动播放下一条**：修正原来 Hook 只在应用启动时、开关开启时才安装的问题。Hook 现在始终安装，根据实时开关返回原始值或启用功能。额外利用播放进度到末尾后延迟核对同一可见 Cell：原生还没切换才尝试向下翻页，降低双跳概率。暂只适配能够识别为竖向 UITableView/UICollectionView 的 Feed。
4. **最高画质**：默认开启，优先将最高码率版本放在首位、并保留其他版本列表。最终是否使用最高画质仍依赖播放器自适应策略、账号、CDN 与源视频清晰度。
5. 保留此前长按面板、透明底栏、默认下移值（进度条 8 pt、底栏文字 6 pt）和定时沉浸式播放功能。

## 设置入口

- 抖音助手首页顶部：**搜索插件设置项**。
- 基本设置 → 视频播放：**自动播放下一条视频**、**图集底部缩略图浏览**、**默认最高画质播放**。
- 隐藏设置中也保留**图集底部缩略图浏览**的开关快捷入口。
