# 影流助手 2.0.13 — 设置页去重与评论毛玻璃微调

## 设置首页（截图红圈）
- 隐藏主设置页原来的左侧“返回”文本、重复的顶部“影流助手”导航标题。
- 隐藏主设置卡片内“已加载插件版本 … · 抖音增强设置”说明，只保留“影流助手”品牌名称、搜索和功能列表。
- 使用小型、无文字的关闭图标替代多余的文字导航，原有左边缘滑动关闭仍可用；二级设置仍有返回按钮。

## 评论区
- 仅评论容器切换为 iOS `UIBlurEffectStyleSystemMaterial`，不修改通知/长按面板模糊样式。
- 默认毛玻璃透明度从 0.82 调为 0.92；只将旧默认 0.82 升级为新默认值，其他自定义数值不覆盖。
- 减少毛玻璃自身白色涂层，避免再次出现昵称、时间、回复周围的白色块。
- 保留 2.0.12 的评论列表 Cell 背景清理及复用逻辑，避免改变评论布局。
