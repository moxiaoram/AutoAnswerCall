# 影流助手 2.0.5：底栏绘制与评论区毛玻璃修复说明

## 目标

- 适配抖音 `com.ss.iphone.ugc.Aweme` 40.8.0，iOS 17.3，RELAXIN 0.4.8 / RootHide。
- 保留 `DYYYHideBottomBg` 和 `DYYYEnableCommentBlur` 两个已有开关及用户持久化配置。
- 底栏只处理背景/渐变视图与对应 CALayer，保留按钮、Feed/Cell 位置和滚动行为。
- 修复原先把 tabBar 的兄弟 `UIVisualEffectView` 不分用途全部隐藏的问题：只处理与底栏所在矩形交叠且高度接近底栏的视图。
- 记录受插件管理背景视图、CALayer 的原始 hidden 和颜色状态；关闭隐藏开关后按原状态恢复。
- 额外处理底栏 `CAGradientLayer` 或命名背景层，修复只处理 UIView 而遗漏图层背景的情况。
- 评论区：不再每次布局叠加不透明白色遮罩；在评论控制器的实际底部弹层选择背景容器加模糊，保持输入区及评论滚动列表透明。
- 评论区没有匹配合适容器时不强行遮盖整页视频；此时功能可能仍不生效，需要真机视图层级信息进一步适配。

## GitHub Actions 构建

按现有 workflow 执行 `SCHEME=roothide`、`AWEMEVISION_STARTUP=full`、`LEGACY_LOADER_NAME=1` 和 `PROBE_ONLY=0`。
**严禁 `-Wl,-undefined,dynamic_lookup`**，继续保持严格链接与 DEB 内容校验。

## 复测顺序

1. 关闭抖音进程、安装新包、在 RELAXIN 白名单确认抖音允许注入，再重新启动。
2. 在 首页 → 隐藏设置 中切换「隐藏底栏背景」，确认按钮仍显示；在不同视频连续滑动和进出评论区测试是否恢复原状态。
3. 在外观设置开启「评论区毛玻璃」，调透明度为 0.80-0.90，打开评论区、上下滚动，再关闭毛玻璃确认背景恢复。
4. 如果底栏看起来仍是黑色，检查底栏下方是否真实绘制了视频画面；只清除背景无法让不在该区域的视频延伸过来。
5. 检查其它功能是否保留，尤其是长按面板、时间进度偏移和设置导航。

## 质量边界

本版本只可执行离线静态检查和 ZIP 校验；没有 iOS SDK/Theos 与手机动态视图树，不能据此声称真正修复成功或已经完成 DEB 编译。
