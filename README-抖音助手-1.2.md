# 抖音助手 1.2 — 抖音 40.8.0 兼容实验版

这是基于 DYYY 开源项目的二次开发版本。保留 MIT LICENSE、上游作者署名与源码链接。

## 本次变化

- 新增「长按解析下载地址」独立入口：复用已配置的解析接口，解析成功后复制直链；多地址时可选清晰度或复制全部地址。
- 底栏透明继续使用「隐藏设置 → 主界面元素 → 隐藏底栏背景」，保留底栏按钮，不新增重复开关。

- 1.1 版本将 Debian 控制文件 `Name` 改为 `抖音助手`，并从 `1.0` 升级到 `1.1`。
- 插件设置入口、设置标题、关于弹窗与侧边栏入口文字改为 `抖音助手`。
- Github Actions 上传的构建产物展示名称改为 `抖音助手`。
- 内部模块 `DYYY`、Debian `Package: com.huami.dyyy`、Preferences 键值 `DYYY...`、数据目录和插件注入筛选器仍保持不变，便于覆盖升级并沿用旧设置，避免两个插件同时注入。
- 本版本打包版本与设置界面版本统一为 `1.2`。
- 原有抖音 40.8.0 兼容实验改动保留；新功能尚未在真机验证。

## 构建

```sh
make clean package SCHEME=roothide
```

需预先安装 Theos 与相应 iOS SDK。此环境仅完成源码与 ZIP 验证，尚未编译 .deb 或真机运行测试。
