# 抖音助手 1.9 · 视频上下错位修复（源码版）

## 根据 1.8 真机截图定位的问题

- **自动下一条的半屏偏移**：1.8 使用 `UITableViewScrollPositionMiddle` / `UICollectionViewScrollPositionCenteredVertically` 把下一条移到屏幕中间，导致上一条残留在屏幕上方，下一条从半屏开始。1.9 改为依据下一条 Cell 的 `rect` 滚动到顶部，并检查目标 Cell 是否接近整屏；用户正在滑动时不介入。
- **透明底栏导致 Feed 高度异常**：1.8 把 `隐藏底栏背景` 也当成强制全屏，影响 `AWEFeedTableView`、`AWEAwemeDetailTableView` 以及播放器容器大小。1.9 新增默认开启的「视频界面防错位」稳定模式，底栏仍透明，但不再强制篡改视频列表/Cell 的几何尺寸。原来的「全屏几何修改」在稳定模式下停用；关闭稳定模式可恢复旧行为，但**不推荐**。
- **40pt / 60pt 大幅偏移导致时间轴和文字贴边**：默认改为进度 **6pt**、底栏标题 **3pt**，幅度最大分别 **12pt / 8pt**，还增加实际屏幕底部安全区限制。`layoutSubviews` 不再直接覆盖抖音原有 transform，而是跟踪基础变换，避免重复加偏移。
- 安装 1.9 时旧版 40/60 或任何超出安全范围的设置会被迁移到 6/3，原值另存到偏好键 `DYYYOldVideoProgressDownOffset18` / `DYYYOldTabTitleDownOffset18`。

## 其他功能

保留 1.8 的长按菜单、设置搜索、图集缩略图、画质、视频下载解析、定时沉浸和自动播放下一条的源码逻辑。此次主要针对截图中的上下两条视频错位问题，**不代表其他功能已通过设备验证**。

## 验证步骤

1. 备份旧版/偏好设置，编译、安装并彻底杀掉抖音进程后重启。
2. 检查插件首页显示「已加载插件版本 1.9」。确保「视频界面防错位（推荐）」开关为开，进度和底栏微调分别为 6 和 3（若仍错位，可先改成 0/0）。
3. 连续上下滑动至少 10 条视频，测试播放结束自动下一条时是否能铺满屏幕、没有上下视频分割；同时测试透明底栏与沉浸式的兼容。
