# 影流助手 2.0.17 — 头像关注小星星

- 将抖音头像下方的关注加号外观替换为截图中的 **白色胶囊底 + 红粉描边五角星**。为了避免原 JPEG 的模糊、头像背景、锯齿，使用 UIKit 贝塞尔路径按设备 Retina 分辨率实时绘制，可缩放。
- 保留 `AWEPlayInteractionFollowPromptView` 原生容器，**只增加不可交互的装饰层**；原有点击关注、取消、转场、头像功能由抖音自身处理；LOTAnimationView 的视觉透明度可按设置恢复，不更改触摸区域。
- 隐藏头像/隐藏关注提示设置仍优先，已经关注时不额外显示星星；选项 **界面设置 → 图标自定义 → 头像关注加号替换成红色小星星** 默认开启，可关闭。
- 主界面上四个点赞/评论/收藏/分享图标维持 2.0.16 原设计。底栏透明尚无真机验证。
- 新增 `scripts/check_217_follow_star.py` 并接入 GitHub Actions 预检。
